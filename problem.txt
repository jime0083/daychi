# Daychi COFFEE MAP - 問題管理 (problem.txt)
# 運用ルール:
# - 開発中に見つかった問題(想定した動きをしない、デザイン崩れ等)は全てここに記録する
# - 修正プロセス(CLAUDE.md「問題修正プロセス」参照・省略禁止):
#   問題共有 → problem.txtに記録 → 原因を徹底調査 → 原因特定 →
#   タスクを切り出しprogress.txt/manual-work.txtに追加 → 修正作業
# - 問題IDは P-001 から連番で付与する
# - 原因調査・特定・切り出しタスクの欄を埋めずに修正作業を開始してはならない

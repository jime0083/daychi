書体

ロゴは決定済みの Oleo Script と Vollkorn。見出しや店名にも Vollkorn(Black)を使い、ロゴと同じ雰囲気をそろえます。本文の日本語は、丸みのある Zen Maru Gothic で柔らかくします。

レトロな印刷物の質感

青い面には小さな網点(ドット)を薄く重ね、選択中の動画や詳細シートには黄色の縁取りと、少しずらした影を付けます。ロゴの「黄色い縁取り」を画面の部品にも広げたものです。

地図のピン

ピンは黄色で、選んだ店舗は緑の縁取りで少し大きく、それ以外は青の縁取りにします。地図の色は変えません(OpenFreeMap のまま)。
